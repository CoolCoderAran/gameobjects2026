
# Changelog

All notable changes to GameObjects will be documented in this file.

The format is based on the principles of
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project follows semantic versioning where practical.

## [Unreleased]

### Added

- Initial modernization project structure.
- Documentation for installation and contribution.
- Modern packaging configuration.
- Development tooling configuration.

- Began transitioning from the historical GameObjects 0.0.3 codebase.
- Replaced legacy installation instructions with modern Python packaging.

### In Progress

- Review of the original source code.
- Verification of original licensing information.
- Modernization of Python syntax.
- Addition of automated tests.
- Development of modern vector and matrix APIs.
